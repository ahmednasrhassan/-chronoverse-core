# Federal Reserve Policy + EFFR Evidence Foundation V1

Inactive, dependency-only acquisition. No runtime registration, scheduler, product/UI caller, credentials, FRED, DDP acquisition, or intermediary fallback.

## Official evidence verified before implementation

- [Federal Reserve press releases](https://www.federalreserve.gov/newsevents/pressreleases.htm), [open market history](https://www.federalreserve.gov/monetarypolicy/openmarket.htm), and [policy-rate reference](https://www.federalreserve.gov/economy-at-a-glance-policy-rate.htm) establish the publisher and target-range concept. History/reference tables are supporting evidence, not event-release clocks.
- The actual HTML of the [January 29, 2025 statement](https://www.federalreserve.gov/newsevents/pressreleases/monetary20250129a.htm) provides `div#content[role=main]`, `div#article`, `p.article__time`, the FOMC statement h3, `p.releaseTime`, the policy paragraph and a linked Implementation Note. Verified maintain wording binds an explicit federal funds target range.
- [December 18, 2024](https://www.federalreserve.gov/newsevents/pressreleases/monetary20241218a.htm) verifies lower/by-fraction/to wording and shows a dissenting preferred range that must not substitute for the Committee decision. [July 26, 2023](https://www.federalreserve.gov/newsevents/pressreleases/monetary20230726a.htm) verifies raise/to wording and explicit EDT release labeling.
- The [January 29 implementation note](https://www.federalreserve.gov/newsevents/pressreleases/monetary20250129a1.htm) links back to the statement. Its FOMC domestic policy directive contains the explicit January 30 effective date and the matching target range. IORB, repo and discount rates are different facts and are excluded.
- The [Board's DDP retirement announcement](https://www.federalreserve.gov/data/data-download-fred-information.htm) confirms planned DDP retirement. This foundation has no DDP dependency.
- [New York Fed EFFR](https://www.newyorkfed.org/markets/reference-rates/effr) and [methodology](https://www.newyorkfed.org/markets/reference-rates/additional-information-about-reference-rates) establish the volume-weighted median of overnight FR 2420 transactions, prior-business-day observations, approximate 9 a.m. publication, dollar volume rounded to billions, revisions and contingency annotations.
- The official EFFR page links [Markets Data APIs](https://markets.newyorkfed.org/static/docs/markets-api.html). Its Swagger UI loads [the official OpenAPI YAML](https://markets.newyorkfed.org/static/docs/markets-api.yml): GET `/api/rates/unsecured/{ratetype}/search.{format}`, `effr`, `json`, inclusive `startDate`/`endDate` in yyyy-MM-dd, JSON `refRates` records. No pagination mechanism or publication timestamp is declared for this operation.
- A bounded [official two-day response](https://markets.newyorkfed.org/api/rates/unsecured/effr/search.json?startDate=2025-01-29&endDate=2025-01-30) was inspected solely for contract verification. It returns `effectiveDate`, `type: EFFR`, **percentRate**, targetRateFrom/To, volumeInBillions and revisionIndicator, plus percentile summaries. The YAML incorrectly labels the rate property `percent`; implementation binds the verified actual `percentRate`, never guesses an alias. YAML documents numeric footnoteId and string revisionIndicator; these are preserved opaquely if supplied.

## Bound capability and representation

Known dated statement URLs only: `https://www.federalreserve.gov/newsevents/pressreleases/monetaryYYYYMMDDa.htm`. Notes are acquired only when the official statement links the matching `a1.htm` page. Both document headings/dates and the reciprocal note link must agree. The parser scopes to the official main/article/body and the exact Committee decision context, not arbitrary percentages. Unsupported historical documents and future structural changes fail closed; universal FOMC compatibility is not claimed.

The actual HTML uses optional closing tags in navigation and the release paragraph. A quote-aware scan excludes comments and non-content regions, requires a uniquely identified and explicitly closed main div, and applies HTML paragraph endings before the existing bounded XML parser processes that fragment. This avoids treating malformed XML navigation as an ancestor of the official article. Tests use these observed HTML conventions; no document content is executed.

FOMC captures one dated policy decision with both bounds, percent unit, the source action verb, URLs, nullable effective date and nullable exact release timestamp. Effective dates come only from the note's FOMC directive, never another operating rate. Explicit EST/EDT release labels are converted to Unix seconds; missing, approximate or unspecified-zone labels remain unavailable. Last Update is ignored. Any acquired note mismatch/failure prevents the complete acquisition from being captured or written.

EFFR requests are explicit inclusive windows of at most 31 calendar days, starting on/after March 1, 2016, when the publication fields changed. The pre-2016 schema is unsupported. Unknown record/envelope fields fail closed rather than silently dropping an unrecognized quality marker or pagination signal. Whitelisted percentile summaries are not selected canonical facts. The observation retains the published rate, optional dollar volume, optional associated target range, footnote identifier and opaque revision marker; missing optional values are explicit nulls. Footnote text and exact EFFR publication timestamps are unavailable in the proven API contract. No timestamp is synthesized from approximate publication times.

The existing statistical canonical contract gains only `daily` and `event-date` civil-date reference periods. Monthly/quarterly semantics are unchanged. The generic vintage engine and its CAS script remain unchanged. FOMC uses a distinct key per dated decision; EFFR uses its own series key. A bounded EFFR capture is a captured window, not a synthesized complete history.

The numeric FOMC observation carries the lower bound; its versioned `us-policy-source-fact-v1` annotation carries the complete structured decision, including both bounds and supported timestamps/URLs. EFFR carries its rate and a separate structured annotation. `readUsPolicyFactsV1` validates and returns the complete facts. Neither family is substituted for the other.

`us-policy-evidence-v1:sha256:` includes the complete locked publisher/source specification and normalized selected facts/annotations. Capture time and transport order are excluded; source-supported publication timestamps remain semantic content. This is Chronoverse content identity, not a claimed official revision ID or cryptographic publisher signature.

knownAt equals the trusted successful completion fetchedAt and Redis score, sampled after the complete acquisition unit validates. Historical observations acquired now are known now. As-known reads require knownAt <= boundary. Existing unchanged/stale/conflict/CAS semantics apply; no overwrite, expiry, trimming or backdated history. Dependency programming defects propagate. FOMC and EFFR are independent acquisitions: later failures/cancellation cannot undo an earlier successful append.
